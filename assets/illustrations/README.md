# タイプ別イラスト配置フォルダ

ここに `<タイプコード>.png`（正方形推奨、320×320px以上）を置くと、結果画面の
イラスト枠（`#result-illustration`）に自動的に表示されます。画像が無いタイプは、
タイプ名の頭文字を丸アイコンで代替表示します（コード変更不要）。

## ファイル名（タイプコード）一覧

- PA_fast.png（船長）      / PA_slow.png（大黒柱）
- BC_fast.png（仕掛け人）   / BC_slow.png（軍師）
- DE_fast.png（実況者）     / DE_slow.png（観察者）
- FG_fast.png（旅人）       / FG_slow.png（職人）
- HI_fast.png（応援団）     / HI_slow.png（聞き役）
- JK_fast.png（太陽）       / JK_slow.png（癒し系）
- LM_fast.png（ムードメーカー）/ LM_slow.png（包容力）
- NO_fast.png（盛り上げ役）  / NO_slow.png（社交家）
- balance.png（バランス型）

対応関係の詳細は `../../js/data-types.js` を参照してください。
